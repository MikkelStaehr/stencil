# Inspiration

Where to look before building, split by Stencil's motion shelves. Each line says what a link is good for and whether it is free or paid. design-lead reads this file when it writes a spec for a website or a new screen.

Licences were checked on 2026-10-21. Check the licence again for each component before copying any code.

## Apps (Applications, Web applications)

- [React Bits](https://reactbits.dev): animated React components such as counters, lists, docks and backgrounds. Free. MIT + Commons Clause: you may use a component inside an app or website, but never resell the components, and keep the copyright notice with copied code. Many components need Motion or GSAP, so check the dependencies.

## Websites (Website/Design)

- [Uilora](https://www.uilora.com): premium website sections and heroes. Paid. Use it for inspiration only; no code from here goes into a repo.
- [Lenis](https://lenis.dev): smooth scroll that works with GSAP ScrollTrigger. Free, MIT. Websites shelf only, with native scrolling under reduced motion.

## Both

- [21st.dev](https://21st.dev): community shadcn/ui components. Freemium. The licence is set per component.

## Tools to assess later

- [emilkowalski/skills](https://github.com/emilkowalski/skills): agent skills for motion and UI polish. Stencil's motion tokens and motion laws are based on them. Free, MIT.
- [pbakaus/impeccable](https://github.com/pbakaus/impeccable): PRODUCT.md, critique and audit commands, and detector rules. Free, Apache 2.0.
- [leonxlnx/taste-skill](https://github.com/leonxlnx/taste-skill): art direction for websites. Free, MIT.
